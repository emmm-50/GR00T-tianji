# GR00T 天玑影子联调结果（2026-11-20）

天玑 AGX Orin 上完成六块推理：三块录包回放共得到 **68 条**内存 Host 右臂候选；三次现场只读快照各得到 **1 条**候选，尚未达到持续 15 Hz。模型每块使用 seed 42；现场 ROS 只采集图像和反馈，未执行机器人动作。

模型加载 30.83 s。六块 GPU 推理中位 845.4 ms，范围 776.7–1,877.5 ms，首块之后范围 776.7–859.9 ms。采集、保存和名义 FK 的中位分别为 3.488 s、13.80 ms 和 4.05 ms，范围分别为 2.798–4.093 s、4.14–25.28 ms 和 3.46–4.64 ms。现场采集包含 ROS 发现与一秒图像历史积累；相机曝光与反馈的物理同步未测量。

## IK 与内存 Host

最终 71 条候选均获成功 ACK，右臂七轴值与 IK 输出一致，左臂、夹爪及 Host 内部 IK 发布均为零。录包按原时间轴的 15 Hz 区间末编排，真实内存回调间隔中位 836.85 ms，范围 718.55–979.08 ms；录包目标 IK 为 717.13–998.37 ms，Host 为 1.266–2.943 ms。

首轮现场 120 个目标全部跳过：108 个进入 IK 前时间不足，12 个计算后过期。最终轮预留至少 1 s 求解，120 个目标中 42 个已过期、75 个提前量不足、3 个收到。现场快照到实际回调范围 1.935–2.068 s；现场 IK 范围 730.27–739.51 ms，Host 1.725–1.968 ms；成功候选位置残差 9.09–13.47 mm、旋转残差 157.13–268.43 mrad（约 9.00–15.38°）。ACK 和残差分别表示软件接收与名义 IK 结果，不代表物理跟踪精度。

用三组对应种子离线保持各自入选目标，第一段残差得到重现；积分 200 ms 后最大残差降至 0.198 mm、0.794 mrad，332 ms 时均达到数值精度。积分到 666 ms 的实际计算约 7.6–7.8 s，表明这些目标在名义模型中可收敛，单区间结果受积分时间限制。

录包块内相邻候选最大七轴差为 0.03886–0.05875 rad，跨块为 0.19204–0.20276 rad。现场每块仅一条，无法计算块内步长；跨块最大差为 0.14929–0.23093 rad，观测种子到候选最大差为 0.20724–0.23106 rad。

## 跨具身假设与后训练

六块候选相对观测的最远位移为 77.7–199.3 mm、最大转角为 10.54–33.28°。工具沿 Z 偏移 50 mm 的假设使候选位置最多变化 5.04–9.92 mm；工具绕 Z 转 90° 的假设使位置最多变化 61.25–261.66 mm、角度最多变化 8.17–16.08°。这些都是同一输出的几何敏感性，不是新推理或标定结果。

六块输入的右关节代理第 1、2、3、6 维超出 DROID checkpoint 的 q01–q99，夹爪输入代理在范围内。夹爪输出在录包为 0–0.010、现场为 0.965–0.988；这不能证明实体抓取、夹爪闭合程度或 TCP 精度。

既有橙子示教数据可用于准备单任务后训练：40 集、27,887 帧训练，10 集、7,087 帧整集留出。应保留夹爪命令与 18,268 帧初始开态推定的来源，并用未参与调参的整集评估。数据转换、训练和 checkpoint 回读尚待验证。
